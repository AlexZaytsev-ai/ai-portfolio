# Сайты и автоматизация — портфолио Александра Зайцева

Отдельная коммерческая страница в существующем GitHub Pages проекте:
https://alexzaytsev-ai.github.io/ai-portfolio/web-design/

- Реальный проект: дизайн и доработки сайта магазина «Барьер», ИИ-консультант в MAX и передача обращений сотруднику.
- Учебные проекты Tilda: Structura (пять страниц), Dubai Estate и лендинг психолога.
- Дизайн-концепты Figma 2022 года: Wow Snow Shop, кулинарный курс и Men’s Health.
- Лонгрид исключён из этой подборки.

Страница статическая: HTML, CSS и JavaScript, без сборщика и сторонних скриптов. Контакты ведут в Telegram и почтовое приложение; формы отправки на самой странице нет.

Скриншоты открываются в диалоговых окнах с описанием личного вклада. На Tilda-проектах нет выдуманных публичных ссылок: пока представлены предоставленные скриншоты. Анимация оригинальных сайтов не воспроизводится в статичных галереях.

Изображения подготовлены из предоставленных автором материалов; баннер «Барьера» взят с действующего сайта. Шрифт Inter и лицензия OFL находятся в общей папке `../assets/fonts/`.

Локальный просмотр: запустить HTTP-сервер из корня репозитория и открыть `/web-design/`.
