ПРОЕКТ ДЛЯ РЕАЛЬНОГО ЗАКАЗЧИКА

Барьер
AI-помощник в MAX

Задача Консультировать покупателей магазина дверей «Барьер» и передавать обращения сотрудникам с контекстом разговора.

Реализация n8n принимает сообщения из MAX, передаёт историю из PostgreSQL в LLM и управляет режимами ИИ, ожидания и общения с сотрудником. Ответ сотрудника через Reply возвращается покупателю в тот же чат.

Статус Основная функциональность готова. Проект подготовлен к тестированию заказчиком.

02 / 05

ОБРАБОТКА ДОКУМЕНТОВ

AI Invoice
Processing Engine

Задача Убрать ручной перенос данных из PDF-счетов и повторную запись документа.

Реализация n8n берёт PDF из Gmail, AI извлекает реквизиты. После проверки полей и дублей по ИНН и номеру n8n сохраняет счёт в PostgreSQL, а отдельный сценарий синхронизирует его с Bitrix24.

Результат Новый проверенный счёт попадает в PostgreSQL и Bitrix24, менеджер получает уведомление в Telegram.

n8nGmailPostgreSQLBitrix24

ПОДБОР ПЕРСОНАЛА

AI Resume
Screening Engine

Задача Сделать первичный разбор PDF-резюме последовательным и проверяемым.

Реализация AI анализирует опыт и навыки. Candidate Validation API проверяет оценку; n8n выбирает маршрут: approved, manual_review или rejected.

Результат После успешной проверки каждый кандидат получает подтверждённый статус approved, manual_review или rejected; он сохраняется в Google Sheets.

04 / 05

ПОДДЕРЖКА

AI Support
Assistant

Задача Сократить ручную сортировку обращений из Telegram.

Реализация AI определяет отдел, приоритет и тему, не отвечая клиенту. n8n записывает данные и маршрутизирует запрос по правилам.

Результат Каждое обращение записывается в Google Sheets и передаётся ответственному отделу в Telegram; неясные случаи идут на ручную проверку.

05 / 05

API / ВАЛИДАЦИЯ

Candidate
Validation API

Задача Проверять оценку кандидата независимо от AI-модели.

Реализация Отдельный API на Node.js/Express принимает оценку от 0 до 100 и сопоставляет её с заданными порогами.

Результат По фиксированным правилам API возвращает approved, manual_review или rejected; некорректные данные отклоняет с кодом HTTP 400.
